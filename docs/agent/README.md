# Agent work records

This directory contains portable work records for the repository's six-phase workflow.

- `specs/<slug>.md` records acceptance criteria and edge cases before implementation.
- `work/<slug>.md` records the ordered implementation tasks and verification evidence.
- `decisions/ADR-<number>-<slug>.md` records costly architectural decisions.

Source, configuration, and tests remain the authority for implemented behavior. These records explain intent, scope, and evidence; they do not override the running code.
